# ✦ Portfolio personal

Sitio web profesional de presentación personal y portfolio de proyectos. Reúne perfil, experiencia, formación, habilidades y enlaces a trabajos publicados en GitHub.

## ✨ Contenido
- Presentación profesional.
- Experiencia en atención al cliente, soporte y operaciones administrativas.
- Formación técnica y aprendizaje inicial de SQL.
- Proyectos prácticos publicados en GitHub.
- Diseño responsive para escritorio, tablet y celular.
- Navegación simple y accesible.

## 🚀 Ver el sitio localmente
Descargá o cloná el repositorio y abrí `index.html` en un navegador. No necesita instalación ni dependencias.

## 🧰 Tecnologías
HTML5 · CSS3 · JavaScript (Vanilla)

## 📝 Sobre el contenido
El portfolio está redactado para reflejar experiencia y formación de manera honesta. Los proyectos de programación son trabajos de práctica y aprendizaje; no representan experiencia laboral profesional en desarrollo de software.
